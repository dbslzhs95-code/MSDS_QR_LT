PACK - 파일 암호화

선택한 파일들을 하나의 .mspack 파일로 암호화합니다. 파일명/경로 목록도 암호화된 내부에 들어갑니다.

대기 중

UNPACK - 파일 복호화

암호화된 .mspack을 열어 원본 파일을 복원합니다. Chromium 계열에서는 폴더 저장을 지원하고, 미지원 브라우저에서는 파일별 다운로드를 사용합니다.

대기 중

비밀번호 변경 - 재암호화

기존 암호를 풀어 평문 파일을 디스크에 저장하지 않고, 새 비밀번호로 다시 암호화합니다. 여러 개의 .mspack을 한 번에 변경할 수 있습니다.

대기 중

파일 형식 / 보안 설정

암호화: AES-256-GCM

키 생성: PBKDF2-HMAC-SHA-256, 600,000회

Salt: 파일마다 무작위 16바이트

IV: 파일마다 무작위 12바이트

형식: MSPK v1. 헤더에는 버전·반복횟수·Salt·IV만 저장되며, 원본 파일명과 내용은 암호화됩니다.

주의: 비밀번호를 잊어버리면 복구할 수 없습니다. 원본은 별도 안전한 위치에 보관하세요.
